# APB Timer
Блок состоит из двух таймеров. Доступ к каждому из таймеров осуществляется по общей APB шине. Базовый адрес блока (BASE) - 0xE0000000

# Описание регистров
Далее представлено описание регистров для таймера (каждый таймер имеет одинаковый набор регистров). Размер адресного пространства для каждого из таймеров - 0x10. Базовый адрес с номером N (нумерация с 0) можно определить по следующей формуле:  $$TIMER_NBASE = BASE + N*0x10 $$

## Register map
 RegisterName | Offset |Access | Reset Value | Description | 
 --- | --- | --- | --- | --- | 
 TIME | 0x0 | rw | 0x0 | Содержит текущее значение таймера. Таймер имеет внутренний делитель, с помощью которого можно задать интервал для увеличения значения регистра. |
 CTRL | 0x4 | rw | 0x0 | Управление таймером: старт/остановка таймера, значения интервала делителя. |
 CMP | 0x8 | rw | 0x0 | Если значение TIME >= CMP, то таймером будет инициировано специальное прерывание. |
 
## TIME

 Name | Bits |Access | Reset Value | Description
 --- | --- | --- | --- | --- | 
 TIME | [31:0] | rw | 0x0 | Текущее значение счетчика таймера |

## CTRL

 Name | Bits |Access | Reset Value | Description
 --- | --- | --- | --- | --- | 
 EN | [0] | rw | 0x0 | Таймер работает, если бит установлен |
 PRE | [5:3] | rw | 0x0 | Значения интервала делителя. Если в поле PRE записан 0, то значение счетчика TIME увеличивается каждый такт. Иначе - значение счетчика таймера увеличивается через число тактов, которое записано в PRE поле.  |


## CMP

 Name | Bits |Access | Reset Value | Description
 --- | --- | --- | --- | --- | 
 CMP | [31:0] | rw | 0x0 | Будет инициировано прерывание при достижении  в TIME значения CMP|


# Прерывания

Таймер генерирует прерывание, если значение в регистре TIME равно значению в регистре CMP  

## Генерация прерывваний

При возникновении события таймером будет сгенерировано прерывание по следующему алгоритму:
1. Возникновение событие (TIME==CMP).
2. На следующем такте будет установлена соответсвующая линия прерывания. Также будет сброшено значение TIME.
3. На следующим такте линия прерваний будет сброшена. Таймер начнет новый отсчет.


# Программирование таймера

Для работы с таймером необходимо выполнить следуюищие действия:
1. Опционально - установить значение в CMP регистр. Выставить начальное значение в TIME 
2. Настроить prescaler таймера (поле PRE в CTRL).
2. Разрешить работу таймера (установить EN бит в CTRL).
